# Roadmap

The project is structured so that each stage is independently verifiable and
each extension keeps the core backtest honest.

## v1 (this repo)

- [x] arXiv corpus fetch (23 categories, 10 commercial fields)
- [x] Phrase mining (word2phrase) + annotation
- [x] Sparse concept graphs (CSR)
- [x] Signals: growth slope, hockey-stick, PageRank, effective conductance G
- [x] Backtest Task A (concept growth) with permutation p / bootstrap CI / lift
- [x] Backtest Task B (pair fusion) with structural + naive controls
- [x] Static site generated from results, GitHub Actions deploy

## v2 — adoption signals (confirming indicators)

- GitHub stars for tool repos matching top concepts
- PyPI download counts for Python packages
- HuggingFace model downloads / trending
- Semantic Scholar citations as impact-weighting
- Fuse into a composite score with explicit component weights

## v3 — product surfaces

- **Radar digest**: weekly top-20 concepts + fusion pairs, generated by CI,
  with change-vs-last-week diff.
- **Field pages with drill-down**: concept → papers → authors → tools.
- **Alerting**: configurable thresholds on G growth / hockey-stick triggers
  (GitHub issue or email via Actions cron).
- **PDF report export** for the watchlist.

## Governance / credibility

- Every release pins `data/results/meta.json` (config + git SHA).
- All evaluation scripts are rerunnable in one command (`run_all.py`).
- Corrections via pull requests; results are data, not opinions.
- Optional: publish the lexicon + results as a versioned dataset
  (Zenodo DOI) so the artifact is citable independently of the code.
