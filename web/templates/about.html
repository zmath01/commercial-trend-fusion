About

Why this project exists, what data it uses, how to reuse it, and how to verify every number on this site.

What this is

Commercial Trend Radar Fusion is an open, backtested research-radar for identifying research concepts and cross-field fusions with commercialization potential. It is built for students, analysts, founders and investors who want a defensible, reproducible view of where applied research is heading — instead of a dashboard of unverifiable claims.

Reproducibility

python scripts/fetch_arxiv.py     # fetch the corpus (arXiv API)
python scripts/run_all.py         # lexicon → annotate → graphs → backtest → predict → site
python -m http.server 8000 -d docs   # preview the site locally

Every artifact the site displays is regenerated by these commands. The committed docs/ folder is the build output; GitHub Actions rebuilds it on push.

Contact & governance

Questions and corrections: open a GitHub issue — everything is public by design. There is no private channel, no paywalled "interpretation", no invite-only group. If the analysis is wrong, the fix is a pull request, not a DM.
